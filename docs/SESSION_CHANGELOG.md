# Session Changelog

This file tracks every change (integrations, features, fixes, config updates) made to this repository during Claude Code chat sessions.

## Rules

1. **Update on every change.** Any time a change is made to the codebase during a session (new integration, feature, fix, refactor, config/dependency update, etc.), a new entry must be added below in the same turn as the change — not batched up for later.
2. **One entry per logical change.** Group a single task's edits into one entry rather than one line per file, but never merge unrelated changes into a single entry.
3. **Newest entries first**, grouped under a `## YYYY-MM-DD` date heading. Add a new date heading when the date changes.
4. **Entry format:**
   ```
   - **[Type]** Short summary of what changed and why.
     - Files: `path/to/file1`, `path/to/file2`
   ```
   Type is one of: `Integration`, `Feature`, `Fix`, `Refactor`, `Config`, `Docs`.
5. **Keep entries factual and concise** — what changed and why, not a restatement of the diff.
6. This file itself is exempt from needing its own changelog entry for formatting-only edits (e.g. fixing a typo in this file), but any change to the **rules** above should be logged as a `Docs` entry.
